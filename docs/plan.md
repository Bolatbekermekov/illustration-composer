# Illustration Composer — спецификация и план реализации

> Исполнение: один агент, задачи по порядку (native/inline), тесты после каждого модуля, коммит на задачу.

**Цель:** веб-сервис, который из объектов Figma-библиотеки (только они, без генерации новых) автоматически
собирает векторные композиции в разных форматах, даёт их редактировать, перекрашивать загруженной палитрой
и выгружать редактируемый SVG.

**Архитектура:** TypeScript-монорепозиторий (npm workspaces), «чистая архитектура»:
`packages/core` — домен и use-case'ы без I/O (изоморфно: сервер + браузер), порты `MetaphorAnalyzer`;
`packages/extractor` — сборка библиотеки из экспортов Figma; `apps/server` — Fastify API + адаптер Claude;
`apps/web` — React-редактор на SVG.

**Стек:** Node 24, TypeScript 5.9, Vitest 4, @xmldom/xmldom, @resvg/resvg-js, Fastify 5, @anthropic-ai/sdk,
React 19 + Vite 7 + Zustand, Playwright.

## Факты из анализа Figma (зафиксированы в коде и тестах)

| Факт | Значение |
|---|---|
| Объекты (10) | Книга, Телефон, Пазлы, Монета, Наушники, Лампа, Цветы (безымянная группа), Кошелёк, Папка, Ручка |
| Состояния | главный (цветной) / фоновый (2 тона): `ink,bg3 → bg3`, всё остальное → `bg1`; геометрия та же |
| Размеры | L (детальный) и S (упрощённый, ровно ~0.5 от L в px; тайлы 500 vs 1000) |
| Масштаб в эталонах | все 18 эталонных композиций используют объекты L в масштабе 1:1; кадр только обрезает |
| Форматы эталонов | 1000×1000, 1200×630, 800×1200 (для S — половина) |
| Базовая схема объектов | Лаванда; роли: bg1 #D7CDF5, bg2 #AA9BF0, bg3 #7864D7, ink #181817, obj1 #F9ECB0, obj2 #F9A3AA, obj3 #FFE3E1, paper #FFFFFF |
| Персик | #FDD7B9 #FAC896 #D27532 #181817 / #F9ECB0 #80DADA #BEEBEB #FFFFFF |
| Мята | #BEEBEB #80DADA #5ABEBE #181817 / #FFD4F2 #6D7BFC #B6C6FE #FFFFFF |
| Перекраска | по ролям (позиция в сетке палитры) — подтверждено на кадрах «SVG-drop» |
| Декор | из тайлов «Фон»: набор «штрихи+конфетти» и набор «плоскость+линии» (цвета фона) |
| Антипример | кадры «SVG-drop»: разный масштаб объектов (лампа ×0.15, ручка ×0.34) — нарушают правило пропорций |

Правила (из задания и вкладок): объекты не меняются (только цвет/состояние), пропорции между объектами
неизменны (единый масштаб), цветовую схему нарушать нельзя (цвета объектов не идут в фон), вывод — вектор.

## Задачи

1. **Палитры и перекраска (core).** `buildColorMap`, `recolorMarkup`, `parsePalette` (JSON / список HEX 6–8 /
   SVG-сетка Figma), `validateScheme` (цвета объектов ∉ цвета фона; bg1 светлее bg3). Тесты: lavender→peach
   даёт ровно цвета кадра SVG-drop; три формата импорта; ошибки валидации.
2. **Экстрактор.** Разбор экспортов (UTF-8 id), объекты по имени/позиции (главные — выше подписи «Фоновые
   объекты»), канонизация цветов, снятие служебных id, bbox через resvg, маски силуэтов (ячейка 8 px),
   декор из тайлов, эталоны из `examples.svg` (позиции восстанавливаются голосованием по смещениям путей).
   Тесты: 10×2×2 вариантов; все цвета ∈ базовой схеме; рендер вырезанного объекта = рендер исходного кадра;
   фоновое состояние = правило 2 тонов; 18 эталонов восстановлены.
3. **Композиция и экспорт (core).** Модель, операции, z-order, `renderComposition`. Тесты: `d` путей в
   экспорте побайтно равны библиотеке; нет `<image>`; уникальные id; клип по кадру; S = 0.5 масштаба.
4. **Авто-раскладка (core).** Оценка: видимость героя ≥ 0.9, второстепенных ≥ 0.7, фоновых 0.3–0.65;
   перекрытия главных ≤ 8% (кроме «предмет на поверхности» ≤ 35%); баланс; без касаний краёв; фон — сзади
   и выше. Поиск: отжиг из нескольких стартов (шаблоны эталонов + эвристики), детерминирован по seed.
   Тесты: эталоны дизайнера проходят оценку; инварианты на случайных наборах; < 400 мс на вариант.
5. **Понимание текста (core).** Сценарий 2: «телефон, 2 монеты, фоновая лампа» → элементы. Сценарий 1
   офлайн: смыслы каталога + стемминг. Тесты на морфологию и синонимы.
6. **Сервер.** `GET /api/library`, `POST /api/compose`, `POST /api/render`, `GET|POST /api/palettes`,
   статика. Адаптер Claude (структурированный ответ, таймаут, фолбэк на офлайн). CLI `compose`.
   Тесты: inject + мок LLM; живой смоук с ключом.
7. **Веб-редактор.** Холст SVG: выбор, перетаскивание, поворот (ручка, Shift — шаг 15°), дубль, удаление,
   слои, состояние главный/фоновый, формат, размер L/S, схема, загрузка палитры, автосборка с вариантами,
   экспорт SVG, undo/redo. E2E Playwright.
8. **Документация и примеры.** README: запуск, архитектура (хранение/извлечение/переиспользование SVG),
   AI-инструменты, 3 примера композиций (SVG+PNG), демо.

## Review Focus

- Неизвестное слово в сценарии 2 → понятное сообщение, а не пустая композиция.
- Палитра с 7 цветами / битым HEX / одинаковыми цветами фона и объекта → ошибка с объяснением.
- Смена L↔S и формата на готовой композиции → позиции сохраняются относительно кадра.
- Нет ключа Claude / таймаут / невалидный JSON от модели → офлайн-анализ, пометка источника.
- Два одинаковых объекта в композиции → уникальные id в экспорте, корректный z-order.
